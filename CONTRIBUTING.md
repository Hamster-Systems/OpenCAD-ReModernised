# Contributing to OpenCAD ReModernised

Thank you for helping to preserve and improve OpenCAD.

This repository is an **independent continuation** maintained by Hamster Systems. The original [OpenCAD repository](https://github.com/opencad-community/OpenCAD) is archived; please direct new contributions for this revival here instead.

## Current priorities

The project is in early development. Documentation, attribution fixes, compatibility investigation, reproducible bug reports and small, well-scoped improvements are especially useful.

## Proposing a change

1. Review the [README](README.md) and existing pull requests before starting.
2. For a small change, fork the repository and create a focused branch.
3. Explain what changed, why it matters, and how it was checked.
4. Open a pull request targeting `develop` in **Hamster-Systems/OpenCAD-ReModernised**.
5. Be prepared to revise the proposed change after review.

GitHub Issues are currently disabled in this fork. Until an issue tracker is available, describe the problem and reproduction steps clearly in the pull request. Do not assume upstream OpenCAD support channels provide support for this fork.

## Pull request checklist

- [ ] My changes are focused and documented.
- [ ] I have tested what I can and clearly described anything untested.
- [ ] I have not included secrets, private user data or credentials.
- [ ] I have preserved original copyright, attribution and licence notices.
- [ ] I have identified any new third-party dependencies, assets and applicable licences.

## Conduct

Be constructive and respectful. Focus discussions on reproducible issues, clear proposals and helping other contributors participate.
